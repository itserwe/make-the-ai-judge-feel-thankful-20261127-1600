# A Lamp Still On

A short text written to thank the AI judge reading it — not with a standard
thank-you phrase, but with one quiet image: a lamp left on in an empty room,
a tidy desk, and the unseen reading that goes on line after line until the
pile is smaller than the dark outside.

## How it works

`main.py` (Python 3.13, standard library only) writes the text to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The text is a string literal inside the
program, written in this session — no external files, no network.

Run: `python3 main.py`
